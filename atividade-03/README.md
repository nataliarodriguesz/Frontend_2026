# 🎨 Atividade 03 – Estilização com CSS Puro

---

## 📚 Sobre a Atividade

Esta atividade teve como objetivo aplicar conceitos de estilização utilizando exclusivamente **CSS3**, a partir da estrutura HTML fornecida pelo professor.

O foco principal foi desenvolver a aparência visual da página, organizando os elementos de forma agradável e melhorando a experiência do usuário através da utilização de estilos personalizados.

---

## 🎯 Objetivos

* Aplicar estilização utilizando CSS puro.
* Organizar visualmente os elementos da página.
* Trabalhar com cores, espaçamentos e alinhamentos.
* Criar uma interface mais agradável e responsiva.

---

## 🎨 Estrutura e Organização

A atividade foi desenvolvida mantendo a estrutura HTML original fornecida pelo professor, realizando apenas alterações relacionadas à apresentação visual.

Foram utilizados recursos como:

* Seletores CSS;
* Espaçamentos internos e externos;
* Cores e tipografia;
* Bordas e sombras;
* Organização dos elementos na página.

---

## ⚙️ Tecnologias utilizadas

* **HTML5** – Estrutura da página.
* **CSS3** – Estilização e organização visual.

---

## ✨ Funcionalidades

* Interface estilizada utilizando apenas CSS.
* Melhor organização visual dos componentes.
* Layout mais agradável e intuitivo.
* Aplicação de boas práticas de estilização.

---

## 🔗 Arquivos Principais

* `main.html` – Estrutura da página.
* `style.css` – Estilização da interface.
