# 🅱️ Atividade 05 – Estilização com Bootstrap

---

## 📚 Sobre a Atividade

Esta atividade teve como objetivo aplicar o framework **Bootstrap** para modernizar a interface disponibilizada pelo professor.

O Bootstrap oferece uma ampla coleção de componentes e utilitários que facilitam a criação de páginas responsivas e organizadas.

---

## 🎯 Objetivos

* Utilizar os recursos do Bootstrap.
* Construir uma interface responsiva.
* Aplicar componentes visuais padronizados.
* Compreender a utilização de classes utilitárias.

---

## 🎨 Estrutura e Organização

O projeto manteve a estrutura HTML fornecida originalmente, adicionando classes do Bootstrap para estilização e organização dos elementos.

Foram utilizados recursos como:

* Containers;
* Grid System;
* Botões;
* Cards;
* Formulários;
* Utilitários de espaçamento.

---

## ⚙️ Tecnologias utilizadas

* **HTML5** – Estrutura da aplicação.
* **Bootstrap 5** – Framework de estilização e responsividade.

---

## ✨ Funcionalidades

* Interface responsiva.
* Componentes estilizados com Bootstrap.
* Melhor organização dos elementos.
* Adaptação para diferentes tamanhos de tela.

---

## 🔗 Arquivos Principais

* `main.html` – Estrutura da página.
* Bootstrap importado via CDN.
