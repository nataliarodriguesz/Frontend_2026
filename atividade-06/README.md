# 💡 Atividade 06 – Lâmpada Interativa

---

## 📚 Sobre a Atividade

Essa atividade consiste em criar uma página simples utilizando JavaScript para manipular elementos HTML através de eventos de clique.

O objetivo é simular o funcionamento de uma lâmpada, permitindo que o usuário a acenda e apague através de botões presentes na interface.

---

## 🎮 Funcionamento

A aplicação possui dois botões responsáveis por alterar a imagem exibida na página:

* **Turn on the light** → troca a imagem da lâmpada apagada pela versão acesa.
* **Turn off the light** → retorna a imagem para a versão apagada.

A troca acontece instantaneamente através da alteração do atributo `src` da imagem.

---

## 🎨 Estrutura e Organização

A página é composta pelos seguintes elementos:

* Um título (`<h2>`) apresentando a atividade.
* Um texto explicativo (`<p>`).
* Um botão para acender a lâmpada.
* Uma imagem (`<img>`) representando a lâmpada.
* Um botão para apagar a lâmpada.

A manipulação é realizada diretamente nos atributos `onclick` dos botões.

---

## ⚙️ Tecnologias utilizadas

* **HTML5** – Estrutura da página.
* **JavaScript** – Manipulação da imagem através de eventos de clique.

> Esta atividade tem como foco apresentar os conceitos básicos de interação com o DOM utilizando JavaScript embutido no HTML.

---

## ✨ Funcionalidades

* Acender a lâmpada através de um botão.
* Apagar a lâmpada através de um botão.
* Alteração dinâmica de imagens.
* Interação simples com eventos de clique.

---

## 🔗 Arquivos Principais

* `main.html` – Estrutura da página e lógica de interação.
* `imagens/pic_bulboff.webp` – Imagem da lâmpada apagada.
* `imagens/pic_bulbon.webp` – Imagem da lâmpada acesa.
