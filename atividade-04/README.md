# 🌼 Atividade 04 – Estilização com DaisyUI

---

## 📚 Sobre a Atividade

Esta atividade teve como objetivo reconstruir a interface fornecida pelo professor utilizando o framework **DaisyUI**, aproveitando seus componentes prontos para acelerar o desenvolvimento e melhorar a consistência visual do projeto.

O foco foi compreender a utilização de classes utilitárias e componentes modernos para criação de interfaces web.

---

## 🎯 Objetivos

* Utilizar componentes do DaisyUI.
* Melhorar a aparência visual da aplicação.
* Trabalhar com elementos reutilizáveis.
* Aplicar conceitos de design moderno.

---

## 🎨 Estrutura e Organização

A estrutura HTML original foi mantida, porém os componentes receberam classes do DaisyUI para estilização.

Foram utilizados elementos como:

* Cards;
* Botões;
* Inputs;
* Containers;
* Componentes visuais do framework.

---

## ⚙️ Tecnologias utilizadas

* **HTML5** – Estrutura da aplicação.
* **Tailwind CSS** – Base do framework.
* **DaisyUI** – Componentes visuais e estilização.

---

## ✨ Funcionalidades

* Interface moderna utilizando componentes prontos.
* Layout mais organizado e responsivo.
* Melhor experiência visual para o usuário.
* Padronização visual através do framework.

---

## 🔗 Arquivos Principais

* `main.html` – Estrutura da página.
* Componentes DaisyUI importados via CDN.
